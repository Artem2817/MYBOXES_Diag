# MYBOXES Diag

Диагностика Mini, Mini v2 и Mini v2 Vib: приложение **0.2.2**, диагностическая прошивка **0.2.1**.

[Скачать и запустить](https://artem2817.github.io/MYBOXES_Ardupilot/diagnostics.html) · [Releases](https://github.com/Artem2817/MYBOXES_Diag/releases) · [Полная инструкция](README.ru.md)

Исходники, профили, тесты и упаковка ведутся здесь от Artem2817. Разработано с помощью AI. Это диагностический комплект; для полёта выбирайте ArduPilot или INAV в общем каталоге.

Проверки: python3 -m pip install -r requirements-dev.txt, затем QT_QPA_PLATFORM=offscreen PYTHONPATH=pc python3 -m pytest tests -q.
